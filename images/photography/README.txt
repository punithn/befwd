PHOTOGRAPHY IMAGES
==================
Drop your photos in this folder using the exact file names below (JPG).
Each one appears in its card on the Photography page automatically.
No file yet? The grey/warm placeholder stays in its place.

Every frame keeps its own ratio. Your photo is cropped to fill it, never
stretched, so any ratio works. Aim for the size shown (or larger) and keep the
subject near the middle.

File name              Frame     Aim for (px)
---------------------  --------  ------------
subject-materials      3:4       1080 x 1440
subject-built-form     3:4       1080 x 1440
subject-people         3:4       1080 x 1440
grade-do               16:10     1600 x 1000
grade-dont             16:10     1600 x 1000
format-feed-4x5        4:5       1080 x 1350
format-tall-3x4        3:4       1080 x 1440
format-square-1x1      1:1       1080 x 1080
format-story-9x16      9:16      1080 x 1920
carousel-1-hook        4:5       1080 x 1350
carousel-2-context     4:5       1080 x 1350
carousel-3-detail      4:5       1080 x 1350
type-do                16:10     1600 x 1000
logo-do                16:10     1600 x 1000

Using PNG or WebP instead? Change the extension in that card's src in index.html.
Want a different crop? Add focus-top, focus-bottom, focus-left or focus-right
to the <img class="photo"> (for example class="photo focus-top").
Update each alt="..." to describe your photograph.
